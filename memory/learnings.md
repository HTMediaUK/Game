# Learnings: Game (HT Dash)

Rules learned from HT's corrections on the expo game. Every agent working on the game reads this first. Written by /thankyou and /learn. A rule seen in two different sessions moves to **Hard rules**.

Format: `- **G-###** (seen n) Rule. *(source · DD/MM/YYYY)*`

- (none yet)

## Look and feel

- **G-001** (seen 1) Characters use the chunky big-head pixel style from HT's references: blocky head about half the height, solid hair shape, 1x2 eyes, thick brows, small mouth, flat skin with one shadow, heavy dark outline. Never long side-profile faces or big toothy grins (read as "Quagmire" and "creepy"). *(HT's style references and corrections · 20/11/2026)*
- **G-002** (seen 1) Dan is clean-shaven in the game. *("remove the beard and give him a normal jaw" · 20/11/2026)*
- **G-003** (seen 1) Dan's t-shirt says HT in white, not the rainbow logo. *("make his t-shirt say HT" · 20/11/2026)*
- **G-004** (seen 1) Running uses short steps with both feet near the ground (option C), at about 10 frames a second, never tied to distance. *("C for the foot", "moves way too fast" · 20/11/2026)*
- **G-005** (seen 1) The backdrop stays uncluttered: few, evenly spaced turbines, cows and trees, and buildings stand on level ground rather than cutting into the hill. *("way too busy … sit nicely in the hill" · 20/11/2026)*
- **G-006** (seen 1) The game over card is the plain GAME OVER panel, not the clapperboard. *("layout of final card is messy, go back" · 20/11/2026)*
- **G-007** (seen 1) Obstacles must read at a glance: the softbox light didn't, so it became a roadworks barrier. *("softbox light isn't clear" · 20/11/2026)*

## Gameplay

- **G-008** (seen 1) Arrow keys choose the runner on the select screen; after that the game is Space only (Enter just saves the name). *("Select screen can use arrows … then it's just spacebar" · 20/11/2026)*
- **G-009** (seen 1) Difficulty rises with time so no run lasts much more than a minute. *("no one should be playing for more than a minute" · 20/11/2026)*
- **G-010** (seen 1) The crash shout is "AHH, SHITE!". *("Change end game message to 'Ahh, shite'" · 23/11/2026, was: "YA BUGGER!")*
- **G-011** (seen 1) The game is called HT Dash. *("Change name to HT DASH" · 20/11/2026)*

## Team (as shown in the game)

- **G-012** (seen 1) Runners and roles: Dan, Managing Director (default); Dave, Production Director; Mark, Creative Director; Beth, Operations & Creative Coordinator; Sam, Editor; Jonas, Creative Producer. *(HT · 20/11/2026, Dave added 23/11/2026)*
- **G-013** (seen 1) Characters stay flat 2D in the game; the 3D spin was tried and dropped. *("Go back to simple 2D Dan" · 23/11/2026)*
- **G-014** (seen 1) Jonas has no goatee. *("Remove the goatee from Jonas" · 23/11/2026)*
- **G-015** (seen 1) The HT logo sits inside the HT DASH title panel, drawn smoothly, never pixelated. *("Move HT logo inside the HT DASH screen" · 23/11/2026, was: top left on every screen)*
- **G-016** (seen 1) Use HT's logo-ring colours rather than invented accents: a colour per runner, ring-segment borders, the ring-style pie timer. *(HT picked ideas 1, 2 and 4 · 23/11/2026)*
- **G-017** (seen 1) After 15 seconds the run goes from the fields into a port with big ships and an offshore wind farm. *(HT · 23/11/2026)*
- **G-018** (seen 1) Flying obstacles glow so they're easy to see. *(HT · 23/11/2026)*
- **G-019** (seen 1) Scene changes happen inside the scrolling world (each layer at its own speed), never as a wipe or split screen. *("come in naturally … seamless" · 23/11/2026)*
- **G-020** (seen 1) Landing on top of an obstacle bounces and scores +5, once per obstacle. *(HT · 23/11/2026)*
- **G-021** (seen 1) The select screen keeps the HT wheel (design C) on the right; the rest is open and uncluttered: no boxed panels, a title lockup and the chosen runner in big type on the left, keycap hints. *(HT: "keep the wheel but … looks too clunky" · 23/11/2026)*
- **G-023** (seen 1) Three lives per run, with a short flashing recovery after each hit; runs still end within about a minute. *(HT · 23/11/2026)*
- **G-024** (seen 1) Runners have two made-up game stats (Speed, Jump) out of 5 that add to 6, shown as bars on the intro; keep them light and never a comment on the real person. *(HT · 23/11/2026)*
- **G-025** (seen 1) Entries must survive a refresh or a dead laptop: keep the browser copy, plus an automatic Notepad (.txt) backup with date, name, email and score, ideally in a synced folder. *(HT · 23/11/2026)*
- **G-026** (seen 1) The run goes country (0s) → port (15s) → Scottish canal (30s), each arriving within the scrolling world. Client places stay generic unless HT names a landmark. *(HT · 23/11/2026)*
- **G-027** (seen 1) The countryside has a mix of UK cattle breeds (Friesian, Highland, Belted Galloway, Hereford, Jersey), as obstacles and grazing in the fields. *(HT · 23/11/2026)*
- **G-028** (seen 1) The game over card shows HT's email: info@ht-media.com. *(HT · 23/11/2026)*
- **G-029** (seen 1) The game must also work by touch (iPad): tap to jump, swipe or tap faces, tap boxes to type, SAVE button, hold the logo for settings. Keyboard controls stay for the laptop. *(HT · 23/11/2026)*
- **G-030** (seen 1) The game is played from GitHub Pages (https://htmediauk.github.io/Game/) once the repo is public; keep `index.html` at the repo root with relative paths. *(HT · 23/11/2026)*
- **G-022** (seen 1) Real-world things (cranes, ships) need their proper parts drawn, not a simplified sketch that reads as broken. *("cranes … seem broken and missing parts" · 23/11/2026)*
